## Existing hitch evidence

The prior production browser trace recorded a 266.7 ms p95 interval in the cold Today to Money sample and one Long Task. Money to Plan on the same run had a 17.3 ms p95. The transition first entered a visible animation state in both. This rules out a purely short visual distance as an explanation for cold behavior. Code paths include synchronous style and bounds reads in jumpTo, a React destination commit and a second layout effect for document scroll restoration, then separate content animations and a React Motion indicator. The first Plan visit can also reach Suspense. Benchmark the phases independently. Physical WebView profiling is an open verification item.
