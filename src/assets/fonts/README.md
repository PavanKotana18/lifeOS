# LifeOS bundled typeface

LifeOS bundles the Inter variable font for offline use. The font is Inter v4.1 from the official rsms/inter project (`docs/font-files/InterVariable.woff2`). Its upstream project and SIL Open Font License 1.1 terms are included in `OFL.txt`.

CSS exposes the variable weights 100–900 and places installed Android Noto Sans Indic fonts and system fonts after Inter so unsupported glyphs can fall back locally. No remote font request is used.
